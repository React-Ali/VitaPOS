# VitaPOS
An open-source, offline-first Point of Sale (POS) and Inventory Management system for Pharmacies, Bakeries, and Vet Clinics.

## Features
- Multi-product support (Human, Vet, Bakery)
- Thermal receipt printing (80mm)
- Customer & Supplier Khata (Credit Ledgers)
- Profit & Loss reporting
- DRAP Schedule G/D compliance tracking
- Offline-first architecture using SQLite
- Self-Healing database mechanism

## Installation (For Developers)
1. Clone the repo: `git clone https://github.com/yourusername/vitapos.git`
2. Install dependencies: `npm install`
3. Run in development: `npm run dev`
4. Build for Windows: `npm run dist`
